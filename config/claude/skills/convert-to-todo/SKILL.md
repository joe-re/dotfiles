# Convert to TODO

ブランチの変更をレビューし、改善点をTODOリストとしてmarkdownファイルに出力するスキル。

## Arguments

ユーザーが指定可能なパラメータ：
- **ブランチ名**: レビュー対象のブランチ（省略時は現在のブランチ）
- **ベースブランチ**: 比較対象のブランチ（省略時はmain）
- **出力ファイル名**: TODOファイル名（省略時はブランチ名から自動生成）

## Workflow

### 1. 現在のブランチと状態を確認

```bash
git branch --show-current
git status
```

### 2. todo作成対象の決定

以下のいずれかからtodoを作成する
1. 直前の会話履歴から、todoを作成
2. 2. code-refactorerエージェントでレビュー実行

コンテキストが不明の場合はUserAskQuestionToolを使ってユーザに確認を行う

#### code-refactorerエージェントでレビュー実行する場合

Taskツールを使用してcode-refactorerエージェントを起動し、以下の観点でレビューを依頼：

1. コードの可読性と保守性
2. 重複コードや不要な複雑さがないか
3. 命名規則の一貫性
4. エラーハンドリングの適切さ
5. リファクタリングの余地がある箇所

レビュー用のプロンプト例：
```
このブランチ（{ブランチ名}）の{ベースブランチ}からの変更をレビューしてください。

以下の観点でコードをレビューしてください：
1. コードの可読性と保守性
2. 重複コードや不要な複雑さがないか
3. 命名規則の一貫性
4. エラーハンドリングの適切さ
5. リファクタリングの余地がある箇所

まず `git diff {ベースブランチ}...HEAD` で変更内容を確認し、変更されたファイルを読んでコンテキストを理解した上で、改善点や問題点を指摘してください。

コードを修正する必要はありません。レビューコメントのみを提供してください。
```

### 3. TODOディレクトリの確認・作成

```bash
mkdir -p .local/todo
```

### 4. TODOファイルの作成

レビュー結果をもとに、以下の形式でmarkdownファイルを作成：

**ファイルパス**: `.local/todo/{ブランチ名}-refactoring.md`

**ファイル構造**:
```markdown
# {ブランチ名} リファクタリングTODO

作成日: {YYYY-MM-DD}
ブランチ: {ブランチ名}

## 高優先度

### 1. {タスクタイトル}
- [ ] {サブタスク1}
- [ ] {サブタスク2}

**対象ファイル**: `{ファイルパス}`
**理由**: {改善が必要な理由}

## 中優先度

### 2. {タスクタイトル}
...

## 低優先度

### 3. {タスクタイトル}
...

## 完了済み

- [x] {完了したタスク} (commit: {コミットハッシュ})
```

### 5. コミット履歴から完了済みタスクを抽出

ベースブランチからの全コミットを確認し、完了済みの改善を「完了済み」セクションに記載：

```bash
git log {ベースブランチ}..HEAD --oneline
```

### 6. 結果の確認

作成したTODOファイルの内容をユーザーに表示し、確認を求める。

## Output Format

- TODOファイルは `.local/todo/` 配下に作成
- ファイル名は `{ブランチ名}-refactoring.md` 形式（スラッシュは削除）
- チェックボックス `- [ ]` で未完了、`- [x]` で完了を表現
- 優先度（高/中/低）でセクション分け
- 各タスクには対象ファイルと理由を明記

## Example

入力：
```
/convert-to-todo
```

出力ファイル：`.local/todo/feature-auth-refactoring.md`
```markdown
# feature-auth リファクタリングTODO

作成日: 2026-01-30
ブランチ: feature/auth

## 高優先度

### 1. AuthServiceの分割
- [ ] 認証ロジックを別メソッドに抽出
- [ ] トークン管理を別クラスに分離

**対象ファイル**: `src/services/auth.service.ts`
**理由**: 単一責任の原則に違反、テストが困難

## 完了済み

- [x] パスワードハッシュ化の実装 (commit: abc1234)
```
